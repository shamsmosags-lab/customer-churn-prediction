# Customer Churn Prediction

A beginner-friendly Machine Learning project that predicts whether a customer may churn based on customer and service-related features.

The project demonstrates a basic classification workflow using Python and Scikit-learn.

## 📌 Project Overview

The project focuses on predicting customer churn and understanding factors that may be associated with customer retention.

The workflow includes:

* Data preparation
* Feature selection
* Train/test split
* Logistic Regression
* Predictions
* Model evaluation
* Confusion matrix
* Business insights

## 🎯 Business Problem

Customer churn can negatively affect customer retention and business performance.

The business needs a way to identify customers who may be at risk of leaving so that retention efforts can be prioritized.

## 💡 Solution

I built a Logistic Regression classification model using customer and service-related features.

The model predicts whether a customer may churn and is evaluated using accuracy, classification metrics, and a confusion matrix.

## 📊 Features

The model uses:

* Age
* Monthly Charges
* Contract Length
* Support Calls

## 🤖 Machine Learning Model

**Logistic Regression**

The dataset was divided into training and testing sets before training the model.

## 📈 Evaluation

The model was evaluated using:

* Accuracy
* Classification Report
* Confusion Matrix

## 💼 Business Insights

* Churn prediction can help identify customers who may be at risk of leaving.
* Customer behavior and service-related information can support retention analysis.
* Businesses can prioritize retention efforts using customer risk predictions.
* Early identification of potentially high-risk customers can support proactive customer engagement.

## ⚠️ Project Limitation

This project uses a small synthetic dataset created for educational purposes.

The model results should not be considered representative of real-world customer churn performance.

A production-ready churn prediction system would require a larger real-world dataset, additional features, stronger validation, and continuous monitoring.
